# Модерация пользовательского контента (App Store 1.2)

Дизайн согласован с владельцем 2026-09-24 по частям в чате. Повод — отказ
App Review сборки 1080 по guideline 1.2 «Safety — User Generated Content»:
приложение позволяет анонимно публиковать контент без мер предосторожности.
Второй пункт того же отказа (2.5.1, закрытые API в `photo_manager` и
`flutter_webrtc`) закрыт отдельно коммитом `affc8287`.

Apple требует восемь вещей. Как каждая закрыта:

| Требование Apple | Решение |
|---|---|
| Рейтинг 18+ | Владелец в App Store Connect → Age Rating |
| Согласие с условиями, нулевая терпимость | Экран условий при запуске (§1) |
| Фильтр оскорбительного контента | Локальный фильтр слов для незнакомых и каналов (§5) |
| Пожаловаться | «Поскаржитися» на сообщение, человека, канал (§2) |
| Заблокировать | Уже есть; жалоба блокирует автоматически (§2) |
| Сразу убрать сообщение | «Приховати» и сама жалоба (§2, §4) |
| Реагировать за 24 часа, удалять, выгонять | Telegram-бот + глобальный бан по ключу (§6, §7) |
| Контакты разработчика | «Профіль → Про застосунок» (§8) |

Сервер не видит переписку — сквозное шифрование. Содержимое сообщения
покидает телефон только в жалобе, по явному действию пожаловавшегося.

## Приложение

### 1. Условия при запуске

- Экран «Правила cubechat» до первого экрана приложения: короткий текст
  (нулевая терпимость к оскорбительному контенту и к пользователям, которые
  его публикуют; нарушителей блокируют; жалобы разбираются в течение
  24 часов), ссылка на полные условия (`docs/legal/terms.*` на сайте) и одна
  кнопка «Приймаю». Выйти из экрана иначе нельзя.
- Принятая версия условий (`termsVersion`, целое число, сейчас `1`) хранится
  в зашифрованном боксе настроек. Экран показывается, если сохранённая версия
  меньше текущей: при первом запуске, один раз у уже установленных после
  обновления, и снова, если текст условий поменяется (версия +1).
- Экстренное стирание сбрасывает согласие.

### 2. Пожаловаться

Пункт «Поскаржитися» в трёх местах: меню долгого нажатия на чужое сообщение
(личный чат и канал), профиль человека, меню канала. Лист с причинами:
спам · образа або цькування · насильство · сексуальний контент · інше
(с необязательным полем «Опишіть» до 500 символов у «інше»).

По нажатию «Надіслати», одной кнопкой и сразу:
1. жалоба уходит на сервер (§6); если сервер недоступен — ставится в очередь
   и досылается при следующем выходе в сеть, до 7 дней;
2. автор блокируется у пожаловавшегося существующим механизмом блокировки
   (для канала — автор сообщения; жалоба на канал целиком — канал скрывается);
3. сообщение, на которое пожаловались, исчезает из ленты у пожаловавшегося.

Тост «Скаргу надіслано. Ми розглянемо її протягом 24 годин». Отменить
блокировку можно как обычно, из профиля.

### 3. Что уходит в жалобе

```
{ v: 1,
  reason: "spam" | "abuse" | "violence" | "sexual" | "other",
  note?: string ≤ 500,
  target: <hex ключа личности того, на кого жалоба>,
  targetNpub?: <его Nostr-ключ, если известен>,
  context: "direct" | "channel" | "airdrop" | "general",
  channelId?: <id канала>,
  message?: { text?: string ≤ 4000, kind: "text"|"photo"|"video"|"voice"|"file"|"sticker"|"other", sentAt: ms } }
```

Медиа не отправляются — только их тип. Жалоба «общая» из §8 идёт с
`context: "general"` без `target`.

Отправляется как подписанное событие Nostr — той же схемой, что
`/register` (`verifyEvent` в `push/src/index.js`, schnorr над secp256k1):
содержимое — JSON выше, `pubkey` — Nostr-ключ пожаловавшегося. Подделать
жалобу от чужого имени нельзя; сервер знает, кто пожаловался, и может
ограничивать частоту.

### 4. Приховати

Пункт «Приховати» в меню любого чужого сообщения: убирает его только на
этом телефоне, без жалобы и без блокировки. Хранится локально рядом с
сообщением, как уже скрытые/удалённые сообщения.

### 5. Фильтр

- Встроенный список грубых слов и корней на украинском, русском и
  английском — `lib/features/moderation/domain/profanity_list.dart`,
  сравнение по словам после нормализации (нижний регистр, ё→е, латинские
  двойники кириллицы, повторы букв).
- Применяется только к входящим сообщениям **от незнакомых** (не в контактах)
  и **в каналах**. Переписку с контактами не трогает.
- Сообщение со срабатыванием показывается свёрнутым: «Приховано фільтром ·
  Показати». «Показати» раскрывает его один раз, на этом телефоне.
- Превью в списке чатов и уведомлении для такого сообщения — «Приховано
  фільтром».
- В Профиле переключатель «Фільтр образливого вмісту», включён по умолчанию.

### 6. Отправка жалоб и глобальный бан — со стороны приложения

- `POST https://push.cubechat.tech/report` (с тем же запасным адресом, что у
  `/register`).
- `GET /banned` при запуске и раз в 6 часов, пока приложение открыто.
  Ответ — список hex-ключей личности и Nostr-ключей плюс подпись сервера
  (Ed25519, публичный ключ сервера зашит в приложение). Неподписанный или
  неверно подписанный ответ отбрасывается; последний хороший список хранится
  локально.
- Для ключа из списка у всех пользователей: сообщения скрыты везде (как у
  заблокированного), его каналы исчезают из списка, новые сессии с ним не
  открываются, AirDrop-предложения и bump от него отклоняются молча.
- Список одинаковый для всех, запрос ничего не сообщает о спрашивающем.

### 7. Экраны и строки

Все строки — в `app_en.arb` и `app_uk.arb`. Цвета через `AppColors`. Листы
через существующий `showGlassSheet`.

### 8. Про застосунок

«Профіль → Про застосунок»: почта `cubechatble@gmail.com`, кнопка
«Повідомити про порушення» (жалоба с `context: "general"`, причина + текст),
ссылки на условия и политику конфиденциальности.

## Сервер (`push/`)

### `POST /report`

- Тело — подписанное событие Nostr; `verifyEvent`, `created_at` не старше
  10 минут и не из будущего больше 1 минуты, `content` — JSON из §3,
  проверка полей и длин.
- Ограничение: не больше 10 жалоб в час с одного ключа, не больше 200 в час
  всего; сверх — `429`.
- Жалоба дописывается строкой JSON в `reports.jsonl` рядом с остальным
  состоянием сервиса (с id, временем, статусом `open`).
- Уведомление в Telegram через Bot API `sendMessage` в чат владельца:
  причина, контекст, короткие ключи, текст сообщения (обрезанный до 1000
  символов), и две inline-кнопки «Забанити» / «Відхилити». Ошибка Telegram не
  роняет запрос: жалоба уже сохранена, отправка повторяется с паузами.

### Кнопки бота

- Сервер получает нажатия long-polling'ом `getUpdates` (без публичного
  webhook — не нужен ещё один открытый адрес). Нажатие принимается только из
  чата владельца (`TELEGRAM_OWNER_CHAT_ID`).
- «Забанити»: ключ из жалобы добавляется в `banned.json`, жалоба —
  `banned`, сообщение в боте правится: «✅ Забанено».
- «Відхилити»: жалоба — `dismissed`, «✖️ Відхилено».
- Команды боту: `/reports` — открытые жалобы; `/unban <ключ>` — снять бан.

### `GET /banned`

- `{ v: 1, updatedAt, identities: [...hex], npubs: [...hex], sig }`, где `sig`
  — Ed25519 подпись канонической формы без `sig` ключом сервера
  (`BAN_SIGNING_KEY`, генерируется один раз при деплое).
- Забаненным Nostr-ключам `/register` и `/turn` отвечают `403`.

### Настройка на дроплете

Переменные окружения сервиса: `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_OWNER_CHAT_ID`, `BAN_SIGNING_KEY`. Шаги для владельца (создать бота
в @BotFather, узнать свой chat id) — в `push/deploy/README.md`.

## Юридические тексты

`docs/legal/`: политика конфиденциальности (en/uk) — новый раздел «Жалобы»:
что уходит в жалобе (§3), кто видит (только разработчик), сколько хранится
(до решения и 90 дней после), глобальный бан-список; условия (en/uk) —
нулевая терпимость, последствия, срок реакции 24 часа, как пожаловаться;
`store-disclosures.md` — новые данные: «User Content (жалобы) — связано с
пользователем, не для отслеживания».

## Ответ Apple

Текст ответа в App Store Connect пишется по итогу: рейтинг 18+, сквозное
шифрование, где в приложении условия, жалоба, блок, скрытие, фильтр, контакты;
жалобы приходят разработчику сразу и разбираются за 24 часа; «выгнать» —
глобальный бан по ключу.

## Тесты

Здесь: экран условий (показ при версии меньше текущей, не пускает без
согласия); жалоба (кодек, подпись, очередь при отсутствии сети, блок и
скрытие одной кнопкой); фильтр (нормализация, срабатывания, только
незнакомые и каналы, «Показати»); бан-список (подпись принимается/
отвергается, применение ко всем поверхностям); сервер — `node --test`:
`/report` (подпись, свежесть, поля, лимиты, запись), Telegram (фейковый
Bot API: отправка, кнопки, чужой чат отклонён), `/banned` (подпись,
`/register`/`/turn` → 403).
