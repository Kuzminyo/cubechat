# CubeChat для Windows — дизайн

Дата: 2026-10-10. Одобрено владельцем в чате («да, делай»).

## Зачем

CubeChat сейчас живёт только на телефонах. Нужен `CubeChat.exe` для Windows:
писать с компьютера, и как отдельный аккаунт, и как второе устройство своего
телефонного аккаунта.

## Что это

- Тот же код Flutter, цель `windows` (папка `windows/` и скрипт Inno Setup
  `windows/installer/cubechat.iss` уже есть).
- Связь — **только интернет-реле** (Nostr), как у телефона без Bluetooth рядом.
  Mesh, BLE-сканирование, store-and-forward по Bluetooth на ПК не запускаются.
- Окно в две колонки при ширине от 900 px: слева список чатов, справа открытый
  чат. Уже — как на телефоне, одна колонка с переходами.

## Вход: два пути на первом экране

### «Новий акаунт»

Обычный онбординг. Свой ключ, контакты добавляются по @нику, ссылке или карточке.

### «Увійти акаунтом телефона»

Копия аккаунта телефона на ПК, телефон **продолжает работать**.

Направление обратное нынешнему переносу между телефонами — у ПК обычно нет камеры:

1. ПК открывает TCP-сервер в локальной сети и показывает QR
   `https://cubechat.app/l1#cubechat:l1:<base64url {host, port, token, password}>`.
   Пароль и токен генерирует ПК.
2. Телефон: Профіль → Дані → «Підключити комп'ютер» → сканер.
3. Телефон подключается, отправляет токен, затем резервную копию, зашифрованную
   паролем из QR (тот же `BackupService.create(password:)`, что у переноса).
4. ПК проверяет токен, принимает до `maxTransferBytes`, делает
   `BackupService.restore`, перезапускает состояние. Сервер одноразовый.

Новый вид QR — `cubechat:l1:`, отдельно от `cubechat:t1:`, чтобы телефон не
перепутал «принять аккаунт» и «отдать аккаунт». Ссылка в https-обёртке с токеном
во фрагменте — как у `t1`.

Телефон после отправки ничего у себя не стирает и не меняет.

## Два устройства, один аккаунт (v1)

Почему это работает без нового шифрования: сообщения шифруются поштучно
(X3DH к ключу личности и подписанному предключу), без ratchet. Одноразовых
предключей нет, подписанный предключ не ротируется (`prekey_service.dart`:
«v1 keeps a single signed prekey (no rotation, no one-time prekeys yet)»).
Значит, копия ключей расшифровывает всё, что придёт.

- Входящие через реле получают **оба** устройства: один ключ, один ящик на реле.
- Ограничения v1, сказать в интерфейсе экрана привязки:
  - отправленное с ПК не появляется на телефоне, и наоборот;
  - «прочитано» у каждого устройства своё;
  - пришедшее только по Bluetooth видит только телефон.
- **Запрет:** ПК, вошедший аккаунтом телефона, никогда не ротирует и не
  перевыпускает предключи и ключ личности. Если однажды появится ротация, она
  должна учесть привязанные устройства — это ограничение записывается
  комментарием в `prekey_service.dart`.

v2 (отдельная спецификация): каждое устройство шлёт копию своих исходящих в
собственный ящик, переписка сходится.

## Что на Windows в v1

Работает: текст, фото и файлы (выбор файла и перетаскивание в окно), голосовые
(запись и Opus есть под Windows), стикеры, каналы, Cube ID, уведомления.

Скрыто (кнопки не показываются, код не вызывается):

| Что | Почему |
|---|---|
| Поблизу, AirDrop, mesh, BLE | нет Bluetooth-стека в приложении под Windows |
| Карта | Google Maps без Windows |
| Камера, кружки | камерные плагины без Windows |
| Звонки | вендорная копия WebRTC собрана только под Android и iOS |
| Перевод | ML Kit только на телефонах |
| Галерея телефона (photo_manager) | вместо неё выбор файла |

Решение «показывать ли» — через один набор флагов возможностей
(`PlatformCapabilities`: `bluetooth`, `maps`, `camera`, `calls`, `translation`,
`gallery`), а не `Platform.isWindows`, разбросанный по экранам.

## Уведомления

`flutter_local_notifications` 17 не умеет Windows. Обновить до версии с
Windows-реализацией или завести узкую обёртку; решается в плане по факту
совместимости версии.

## Сборка и выдача

- `tool/build_windows.ps1`: та же сверка версии и штампа, что у APK
  (`app_build.dart` ↔ `pubspec.yaml`, штамп найден внутри собранного
  `app.so`), затем ZIP и, если установлен Inno Setup, `CubeChat-setup.exe`.
- Версия в `cubechat.iss` берётся из pubspec, а не захардкожена `0.1.0`.
- Задача в GitHub Actions на `windows-latest`: анализ, тесты, сборка,
  артефакт ZIP + установщик.

## Тестирование

- Флаги возможностей: тест, что на Windows скрыты пункты из таблицы.
- Привязка: кодек `cubechat:l1:` (туда-обратно, мусор, короткие токен/пароль),
  и сквозной тест сервер ПК ↔ клиент телефона на loopback с настоящим
  `BackupService` (Hive во временной папке): данные доезжают, неверный токен
  отбрасывается, сервер одноразовый.
- Запуск: `flutter build windows --release` проходит; exe стартует, онбординг
  открывается, сообщение через реле уходит и приходит (проверка руками).

## Не входит в v1

Синхронизация исходящих между устройствами, звонки, перевод, macOS и Linux,
автообновление.
