# Профиль: разделы вместо свалки настроек

Дизайн согласован с владельцем 2026-09-30 по макету
(`C:\Users\kuzme\Downloads\cubechat-profile-maket.png`, исходник —
scratchpad `profile_mock.html`). Жалоба: «очень много всего, глаза
разбегаются, не выглядит дорого». Решение: главный экран профиля — короткий
список разделов в стиле настроек iPhone и Telegram. Каждый раздел открывает
свой экран, как сейчас открывается «Кастомізація».

**Поведение ни одной настройки не меняется.** Меняется только то, где она
лежит и как выглядит строка. Ключи в Hive, провайдеры и тексты подсказок
остаются прежними.

---

## 1. Главный экран профиля

Сверху вниз:

1. **Шапка** — существующая обложка `_ProfileCover` со всем её поведением
   (жест открытия фото, меню). Под именем добавляются:
   - строка `@имя` цветом бренда, если есть Cube ID (иначе ничего);
   - две «таблетки» — **«Моя картка»** (QR-код, `/contact-card`) и
     **отпечаток ключа** коротко (`A3F2 · 9C1D`, нажатие показывает шторку
     с полным отпечатком и кнопкой «Копіювати»). Отдельная карточка с
     отпечатком под обложкой исчезает.
2. **Группа 1:** Cube ID · Конфіденційність і безпека · Сповіщення і
   дзвінки · Зв'язок.
3. **Группа 2:** Чати і медіа · Оформлення · Дані і пам'ять.
4. **Группа 3:** Про застосунок.
5. **Екстрене стирання** — отдельная красная строка. Поведение прежнее:
   подтверждение, затем стирание, без захода в экран.

Строка раздела: цветной квадрат-иконка 34×34 со скруглением 10, название,
справа серым краткое состояние и шеврон. Строки одной группы стоят в одном
стеклянном блоке, между ними тонкие разделители с отступом под иконку.

Краткое состояние справа:

| Раздел | Что показывается |
|---|---|
| Cube ID | `@имя` или ничего |
| Конфіденційність | значение «Хто може писати з інтернету» (Усі / Через запит / Ніхто) |
| Сповіщення і дзвінки | «Тихі години» с интервалом, если включены; иначе ничего |
| Зв'язок | существующий `_connectionSummary` |
| Чати і медіа | ничего |
| Оформлення | существующий `_customizeSummary` (тема) |
| Дані і пам'ять | существующий `_dataSummary` |
| Про застосунок | версия `1.0.0` |

Цвета иконок фиксированные (синий, зелёный, красный, фиолетовый, оранжевый,
розовый, голубой, серый), как в настройках iPhone. Это единственное
осознанное исключение из правила «цвета только через `AppColors`». Они
задаются константами в одном месте (`settings_section_icons.dart`) с
комментарием, почему не следуют теме: иконка раздела — метка, а не
поверхность, и должна узнаваться в любой теме.

## 2. Что в каких разделах

Каждый экран раздела устроен одинаково: прозрачный `AppBar` с кнопкой назад
и заголовком, как в `CustomizeScreen`; внутри подгруппы с серым
заголовком-капсом и стеклянными блоками строк.

| Экран | Маршрут | Подгруппы и содержимое (существующие виджеты) |
|---|---|---|
| **Cube ID** | `/cube-id` (есть) | без изменений |
| **Конфіденційність і безпека** | `/settings/privacy` | *Хто мене бачить*: час у мережі, час прочитання, посилання в пересиланнях, видимий поруч (`_DiscoverableCard`), геолокація на мапі. *Хто може писати з інтернету*: `StrangerReachSelector`. *Захист*: блокування застосунку, фільтр образливого, вимикач мовчання (`_DeadMansRow`, `_GraceRow`) |
| **Сповіщення і дзвінки** | `/settings/notifications` | *Сповіщення*: пробудження (`_PushWakeRow`), тихі години (`_QuietHoursRow`). *Дзвінки*: приймати дзвінки, прямі дзвінки (`callDirect`), дзвінок на заблокованому екрані (Android) |
| **Зв'язок** | `/settings/connection` | Bluetooth-мережа (`_MeshSwitchCard`), транспорт (`_TransportRow`), фоновий режим (`_BackgroundModeCard`), інтернет-резерв і релеї (`_RelayFallbackCard`) |
| **Чати і медіа** | `/settings/chats` | из «Кастомізації»: свайп (`_SwipeCard`), рядок архіву (`_ArchiveRowCard`), швидка реакція (`_QuickReactionCard`), звук кружків (`_CircleAudioCard`), якість медіа (`_MediaQualityCard`), автозавантаження (`_MediaDownloadCard`), мова розшифровки (`_TranscribeLanguageCard`); из профиля — лінза кружків (`circleLens`) |
| **Оформлення** | `/customize` (есть, переименован) | тема, розмір інтерфейсу, скло, нижня панель (`_NavBarCard`) и **мова** (`_LanguageRow` переезжает сюда) |
| **Дані і пам'ять** | `/settings/data` | сховище (`_StorageRow`), передачі файлів (`_FileTransfersCard`), резервна копія (`_BackupCard`), перенесення на новий телефон (`PhoneTransferCard`), оновлення з файлу (`_InstallUpdateRow`, Android) |
| **Про застосунок** | `AboutScreen` (есть) | добавляется строка **Діагностика** (`/diagnostics`) |

«Картка контакту» живёт в шапке («Моя картка») и больше не дублируется в
разделах.

Каждая существующая настройка попадает ровно в одно место. Проверка — тест
(§4), который ищет на экранах разделов заголовок каждой настройки.

## 3. Код

- Новая папка `lib/features/profile/presentation/settings/`:
  - `settings_tiles.dart` — `SettingsGroup` (стеклянный блок с
    разделителями), `SettingsSectionRow` (строка раздела с иконкой,
    состоянием, шевроном), `SettingsSubheader` (серый заголовок-капс),
    `SettingsSectionScreen` (каркас экрана раздела: AppBar и список);
  - `settings_section_icons.dart` — цвета и иконки разделов;
  - по файлу на экран: `privacy_section_screen.dart`,
    `notifications_section_screen.dart`, `connection_section_screen.dart`,
    `chats_section_screen.dart`, `data_section_screen.dart`.
- Приватные виджеты строк переезжают из `profile_screen.dart` (3 150 строк)
  и `customize_screen.dart` в файлы своих разделов **как есть**, со всеми
  комментариями. Делаются публичными только там, где их зовёт другой файл.
  Логика внутри не меняется.
- `_ExpandableSection` и групповые `_privacySummary` уходят, если больше
  никем не используются.
- Маршруты в `app_router.dart` рядом с `/customize`, через тот же
  `fadeSlidePage` и `AuroraBackground`.
- `_frame(framed:false)` внутри виджетов остаётся: виджеты уже умеют
  рисоваться без собственной рамки, а рамку даёт `SettingsGroup`.
- Все новые строки интерфейса — в `app_en.arb` и `app_uk.arb`, затем
  `flutter gen-l10n`. Названия разделов из макета: «Конфіденційність і
  безпека», «Сповіщення і дзвінки», «Зв'язок», «Чати і медіа»,
  «Оформлення», «Дані і пам'ять», «Про застосунок»; подзаголовки из §2.

## 4. Проверка

- Виджет-тест профиля: 8 строк разделов и красная строка стирания;
  нажатие на раздел ведёт на его маршрут.
- Виджет-тест «каждая настройка в одном месте»: для каждого экрана раздела
  список заголовков настроек, которые должны на нём быть (из §2). Тест
  проходит по всем экранам и падает, если заголовок пропал или встретился
  дважды.
- `test/layer_budget_test.dart`: у профиля сейчас бюджет 4 слоя. Новый
  главный экран должен уложиться в него или стать дешевле. Число
  обновляется только вниз, с комментарием.
- Золотые снимки профиля и кастомизации, если они есть, перезаписываются
  только после просмотра PNG «до и после».
- Полный набор без golden-тестов зелёный, `flutter analyze` без ошибок и
  предупреждений.
- На телефоне: пройти по всем разделам, переключить по одной настройке в
  каждом и убедиться, что состояние сохранилось после перезапуска.

## 5. Что не входит

- Изменение поведения настроек, новых настроек нет.
- Поиск по настройкам.
- Переделка экрана «Про застосунок», кроме строки «Діагностика».
