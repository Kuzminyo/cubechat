# Устройства аккаунта «как в Gmail» — дизайн

Дата: 2026-10-12. Дизайн одобрен владельцем в чате («да, пиши спеку и делай»).
Продолжает `2026-10-12-desktop-calls-design.md` (там появился канал «себе и от
себя» для звонков).

## Зачем

ПК входит аккаунтом телефона, копий может быть несколько. На любом устройстве
нужно видеть все устройства аккаунта и уметь выйти на любом другом.

## Что видно

Профиль → Дані → «Пристрої»:
- «Цей пристрій» сверху, ниже остальные: название, тип (Android, iPhone,
  Windows…), «був у мережі …»;
- у каждого чужого — «Вийти»; внизу — «Вийти на всіх інших пристроях»;
- своё название можно поменять; по умолчанию «Android», «iPhone»,
  «Windows · <имя ПК>»;
- честная строка под списком: выход срабатывает, когда устройство выйдет в
  интернет; устройство, которое держат без интернета, сохранит ключи. Полная
  защита — смена ключей аккаунта (не входит).
- выход **телефона с ПК** (или любого устройства, где он единственный
  телефон) — с отдельным предупреждением: на том устройстве всё будет стёрто,
  аккаунт останется здесь.

## Номер и название устройства

- Номер — 16 случайных байт, название — строка до 64 байт UTF-8. Оба в
  защищённом хранилище (`flutter_secure_storage`), **не в Hive**: резервная
  копия и перенос аккаунта на ПК их не уносят, у копии свой номер.
- Экстренная очистка и удалённый выход их стирают — после них устройство
  новое, со своим новым номером.

## Протокол

Новый `InnerPayloadType.ownDevice` = **0xEB** (свободные на 2026-10-12:
0xEB–0xEF, 0xFD–0xFF). Не текстовый URI: это служебное сообщение между своими
устройствами, ему не место в чате, а старые сборки неизвестный тип молча
отбрасывают — ровно то, что нужно.

```
[version:1 = 0x01][kind:1][sentAtMs:8][deviceId:16][тело]
kind 0x01 hello:   [flags:1][platform:1][nameLen:1][name:nameLen]
                   flags bit0 — «ответьте своим hello»
kind 0x02 signOut: [targetId:16]
kind 0x03 goodbye: —
```

platform: 0 неизвестно, 1 Android, 2 iOS, 3 Windows, 4 macOS, 5 Linux.

- Отправляется только на собственный ключ, только через реле, без пуш-тегов —
  тем же путём, что `device`-уведомление звонков
  (`sendCallSignalToOwnDevices` обобщается до отправки любого типа себе).
- Принимается только от собственного ключа; от чужого — отброс с логом.
- Декодер проверяет длины и бросает `FormatException`; версия ≠ 1 — отброс.
- **Переживает окно повторов** (`survivesReplayWindow`): выключенное на дни
  устройство должно получить свой `signOut`. Безопасно: команда адресована
  номеру, а после выхода номер у устройства новый; повтор `hello` только
  обновляет «был в сети» (берётся максимум `sentAtMs`).

## Поведение

- `hello(answer)` — при старте, когда реле подключено, и при смене названия;
  `hello` без флага — раз в 6 часов, пока приложение открыто.
- На `hello` с флагом «ответьте» — свой `hello` без флага (без пинг-понга).
- Список других устройств хранится в зашифрованном Hive (настройки):
  номер, название, тип, последний `sentAtMs`. Устройство, молчащее 60 дней,
  из списка убирается.
- «Вийти» → `signOut(targetId)`; цель сразу помечается в списке «виходить…» и
  исчезает, когда придёт её `goodbye` (или через 60 дней).
- Получив `signOut` со своим номером: `goodbye`, затем **очистка без
  освобождения @ника** (`emergencyWipe(releaseName: false)`) и без снятия
  пуш-регистрации чужого устройства (на сервере один токен на аккаунт; ПК его
  не регистрирует; телефон, который выходит, свой токен не снимает — следующее
  устройство, включившее пуши, перезапишет его). Дальше — экран как после
  экстренной очистки.
- `goodbye` — убрать устройство из списка.

## Что не входит

- Смена ключей аккаунта, отзыв ключей у неподчиняющегося устройства.
- Синхронизация переписки между устройствами.
- Список для сборок до 1147: они не шлют `hello` и в списке не появятся.

## Юридические документы

Политика конфиденциальности: устройства одного аккаунта обмениваются через
реле зашифрованными сообщениями на собственный ключ — название, тип, время;
никто, кроме ваших устройств, их не читает. Удалённый выход стирает данные
на том устройстве.

## Тестирование

- Кодек: туда-обратно для трёх видов, неверная версия, обрезанные тела,
  слишком длинное имя → `FormatException`.
- Контроллер (фейковая отправка/входящие): `hello` при старте с флагом; ответ
  на флаг без флага; список обновляется и сохраняет максимум времени; `signOut`
  чужому номеру — игнор; своему — вызывает выход; `goodbye` убирает; чужой ключ
  — игнор; молчащие 60 дней убираются.
- Очистка без освобождения @ника: `release` не вызван, номер устройства стёрт.
- Экран: список, переименование, подтверждения.

Только вживую: два реальных устройства видят друг друга, выход на ПК с
телефона.
