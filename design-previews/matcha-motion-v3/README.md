# Matcha & Emoji — Collection 03, 2K export

40 animated designs: 20 matcha cat stickers and 20 classic emoji.
Every animation loops over 4 seconds at 25 fps.

Formats:
- png-2k/: 40 transparent PNGs, 2048 x 2048.
- webm-2k/: 40 VP9 WebM animations, 2048 x 2048, transparent.
- Root WebP/GIF/PNG: lightweight preview versions (320 or 512 pixels; GIF 240).

Resolution note: the generated source artwork is smaller than 2048 x 2048.
The 2K files are careful upscaled exports, not native 2K redraws or additional
hand-painted detail. The source drawing style and colors are retained.

Animation uses smooth continuous local mesh motion of one selected drawing.
Paws, tails, heads and props move subtly with periodic easing. This is a motion
concept collection, not full production character rigging or Telegram TGS.

Open index.html in a browser. Click a card and choose the 2K view or downloads.
Some browsers restrict local video or file access; a local HTTP server can be
used if needed. The live preview in Codex already uses a local server.

Built-in ImageGen produced the artwork. prompts.json records the new sheets.
No Flutter app integration is included. validation-2k.json records dimensions
and transparency checks on decoded video frames.
