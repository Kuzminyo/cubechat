Сняты тестовым рендерером Flutter, поэтому подписи выглядят прямоугольниками: в тестах нет шрифта. Проверялась геометрия, а не текст.

- `call-talking.png` — экран разговора: кнопка «свернуть» слева сверху, три кнопки (микрофон, динамик, завершить) поровну по ширине.
- `call-island.png` — свёрнутый звонок: зелёный остров под статус-баром с именем, временем, микрофоном и красной кнопкой; содержимое приложения сдвинуто под него и доступно.
- `circles.png` — кружки в покое прижаты к своим краям без пустого поля вокруг; входящий слева, исходящий справа.
- `customize.png` — «Дія при змахуванні»: слева превью чата, отъехавшего и открывшего панель с иконкой действия, справа зацикленное колесо с двумя линиями, как в Telegram.
